# gdmount

[English](README.md) · **Українська**

Монтування Google Drive у Linux через rclone. gdmount створює системну службу користувача та підтримує GNOME, KDE Plasma й інші стільниці.

## Можливості

- Встановлення rclone і fuse3
- Авторизація акаунта Google через браузер
- Ручний або автоматичний режим двосторонньої синхронізації
- Вибір частоти автоматичної синхронізації
- Локальний пристрій Google Drive, доступний без інтернету
- Перегляд змін, що очікують двосторонньої синхронізації
- Заміна акаунта та повне видалення
- Інтерфейс українською та англійською

## Встановлення

```bash
curl -fsSL https://github.com/PanVena/gdmount/raw/refs/heads/main/install.sh | bash
```

Або запустіть скрипт із репозиторію:

```bash
./install.sh
```

Під час інтерактивного встановлення gdmount запитає мову, режим синхронізації та теки для локальної роботи. Вибрані теки завантажуються на комп'ютер і відображаються за звичними шляхами всередині `~/Google Drive`; окремо відкривати теку копій не потрібно. Для пристрою потрібен `mergerfs`, який встановлювач поставить разом із rclone. Змінна `GDMOUNT_UI_LANG=uk|en` задає мову без запиту.

Під час входу в Google rclone використовує локальний порт `53682`. Якщо його
ще займає попередня спроба входу, інсталятор покаже процес і запропонує
завершити завислий процес rclone перед повторною спробою.

Якщо remote `gdrive` вже є, але його токен застарів, інсталятор сам запропонує
повторний вхід у браузері. Вручну команда rclone має містити двокрапку після
імені remote: `rclone config reconnect gdrive:`.

## Використання

```text
gdmount install [опції]         встановити й змонтувати
gdmount local list              показати локально доступні теки
gdmount local add [ШЛЯХ]        додати теки за номерами або за шляхом
gdmount local remove ШЛЯХ       прибрати теку з локального вигляду
gdmount sync                    синхронізувати локальні теки з Google Drive
gdmount sync-mode               показати або змінити спосіб і частоту синхронізації
gdmount status                  стан монтування, черги й місця на диску
gdmount mode [all|selected]     показати або змінити локальний обсяг
gdmount start | stop            запустити або зупинити диск
gdmount switch-account [опції]  змінити акаунт Google
gdmount uninstall [опції]       видалити створені gdmount файли
gdmount --help                  повна довідка
```

Налаштування зберігаються в `~/.config/rclone-gdrive-setup/config`.

У режимі вибраних тек команда `gdmount local add` додає теки з нумерованого списку, а `gdmount local add ШЛЯХ` додає конкретну теку. У списку можна ввести діапазон `1-3` або поєднати діапазони з окремими номерами, наприклад `1,3-5`. Команда `gdmount mode selected` замінює список або перемикає з усього диска на вибрані теки.

## Локальні теки

Вибрані теки зберігаються локально у службовому сховищі gdmount і з'являються за тими самими шляхами в `~/Google Drive`. У цьому локальному пристрої доступні лише вибрані теки. Їхні файли відкриваються з диска комп'ютера й доступні без інтернету.

Переглянути вибір можна командою `gdmount local list`. Після додавання теки завантажуються й синхронізуються. Команда `gdmount local remove ШЛЯХ` вилучає теку зі списку й архівує локальні дані, що більше не входять до вибору. Тека залишається доступною, якщо вибрано одну з її батьківських тек.

- `manual`: локальні зміни залишаються на комп'ютері, доки ви не запустите `gdmount sync`; фоновий timer не встановлюється.
- `auto`: gdmount синхронізує вибрані теки в обидва боки через заданий інтервал.

`gdmount sync` передає локальні зміни на Google Drive і завантажує зміни з хмари. `gdmount status` перевіряє чергу без передавання файлів і перелічує локальні файли, які очікують на відправку.

Спосіб і частоту можна змінити без повторного завантаження файлів:

```bash
gdmount sync-mode manual
gdmount sync-mode auto --sync-interval 30m
```

Під час нової інтерактивної інсталяції gdmount запитає ці параметри. Для
неінтерактивної інсталяції режим `manual` є безпечним для енергії типовим
значенням; `--sync-interval 0` і старий `--poll-interval 0` також вмикають
ручний режим.

Синхронізація двостороння: видалення передається на інший бік, а одночасні зміни одного файла зберігаються як конфліктні копії. Перший запуск узгоджує наявні локальні й хмарні версії за часом зміни; локальну версію, яку замінено новішою хмарною, gdmount зберігає у своєму службовому архіві. Команда `gdmount switch-account` і встановлення з іншим `--remote` архівують попередню локальну копію. Для нового підключення потрібно вибрати теки для завантаження.

## Видалення

```bash
gdmount uninstall
```

Для видалення без підтверджень використайте `--yes`. gdmount автоматично видаляє запис rclone лише тоді, коли зафіксував точне ім’я remote під час створення. Наявні файли на Google Drive ніколи не видаляються.
